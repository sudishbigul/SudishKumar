## 🛠 Tech Stack

- **Framework**: [Gatsby.js](https://www.gatsbyjs.com/) (v3)
- **Library**: React 17
- **Styling**: Styled Components & CSS Custom Properties
- **Animation**: ScrollReveal & Anime.js
- **Content Management**: Markdown Remark with GraphQL data layer
- **Deployment**: Vercel

## 💻 Local Development & Setup

1. **Clone the repository**:

   ```sh
   git clone https://github.com/sudishk/sudish_kumar.git
   cd sudish_kumar
   ```

2. **Install dependencies**:

   ```sh
   npm install
   ```

3. **Start the local development server**:
   ```sh
   npm start
   ```
   Open `http://localhost:8000` to view the site.

---

## 🏗 Building for Production

Generate the production static bundle:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run serve
```
